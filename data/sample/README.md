# SAMPLE data — not real inventory

`SAMPLE_current_stock.csv` is **made-up test data** for trying the optional stock upload.
The Online Retail II dataset has no inventory levels, so the stock numbers were generated by
`backend/scripts/make_sample_stock.py`: for the 60 best sellers of the last 12 weeks,
stock = average weekly sales × a random 0–6 weeks of cover (fixed random seed).

Format: two columns, `StockCode,CurrentStock`.
